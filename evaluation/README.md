当前尚无应用内真实模型对照成绩。已完成一次当前对话宿主AI开发预实验，见`host-pilot-20261018`；任务设计、参考值阅读和回答在同一上下文完成，非盲测、无独立普通AI基线，不是应用接口端到端测试。自动化数值与引用检查不代表模型准确率。已有用户非结构化试用反馈，不作为正式任务成绩。

正式模型评测建议36题，按三模式交叉覆盖：数值查询6、贡献与比较6、结构解释6、国家角色消歧6、数据缺口6、错误前提与过度推断6。

每题冻结：输入数据指纹、分析条件、用户问题、参考计算、应澄清事项、允许解释、禁止解释、评分条目。正常题与困难题均保留，不因系统失败删除题。

比较组：固定分析页面、普通AI获得相同数据及合理工具条件、完整受限工具与证据流程。不能限制普通组使用计算工具后声称本系统计算更准；三组的工具与信息差异必须写清。

记录任务完成、数字正确、引用存在、引用支持主张、该澄清时是否澄清、无依据结论、时间、失败与重试。资源用量能实测才记录，不估造。引用存在与语义支持分别评分。

保留首次输出和后续重试，不覆盖失败。用保留题调试后，该题转回归题。单助手出题和评分的局限必须披露。

真实试用目标3—5名国贸相关学生：定位主要变化对象、纠正一条份额/增长描述、导出证据报告。实测任务完成情况和卡点，小样本只做可用性反馈，不宣称人群效果。

`source-check`保存官方金额抽查的原始响应与报告。最初计划六项，实际完成两项，第三项遭HTTP429后停止请求；两项均在WITS公布舍入精度内。该抽查不是全部来源认证，也不是跨商品分类普遍等价的证明。
