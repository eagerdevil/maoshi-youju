已实现：本地Ollama与兼容聊天接口配置、受限工具选择、证据包解释、输出结构和引用校验、调用记录。模型设置中填写地址和模型名称后才能实际调用。兼容接口地址应包含服务要求的基础路径，例如以 `/v1` 结尾，程序追加 `/chat/completions`；需支持JSON对象输出。Ollama地址不包含 `/api/chat`，由程序追加。

凭据保存在被忽略的 `config.local.json`，读取接口不返回密钥；导出包排除凭据和数据库。不要把该文件打包提交。模型连接是否可用以真实调用为准；“已配置”不代表调用成功。

AI文本不允许自由生成阿拉伯数字，数值从所引证据显示，以减少数字编造。引用ID存在只证明结构有效，不能保证语义无误，仍需人工复核。pytest模型测试强制隔离本地真实密钥，仅使用测试替身。真实模型试运行与开发测试分别保存，不能混算成绩。

## 导入自己的国家或行业

在“数据与来源”下载CSV模板，按模板提供UTF-8 CSV，金额统一USD：

- `reporter`、`partner`：稳定国家/地区代码；世界伙伴为WLD。
- `reporter_name`、`partner_name`：显示名称。
- `year`：年度；`flow`：M进口或X出口。
- `product`：2、4或6位商品编码，保留前导零；`product_name`：明确的商品名称。
- `classification`：明确H0—H6版本。
- `value_usd`：非负、有限美元金额；缺失留空。
- `status`：observed、explicit_zero或missing。
- 可选`partner_type`：country_or_area、world、aggregate、unallocated；区域汇总本版不允许与成员混用。未指定时非WLD默认按上传者声明的国家/地区处理，上传者须先排除区域合计。

原始文件完整留存。来源URL为上传者声明，程序不会据此认证真实性。重复主键、父子商品重叠、混合分类版本等问题会阻止导入或分析，不会静默修正。
