# 0.4.0：从查看变化，到核查判断

新增“研究诊断”工作台，在模型未连接时也可使用。计算引擎保留0.1.0，分析ID不改变，诊断算法独立标记为1.0.0。

## 新增的研究能力

固定当前报告期，在当前分析区间内选择最多六个基期。默认包含当前基期及最近五个可选基期，内置2019—2023数据默认比较四个窗口。

目标市场模式检查各供应伙伴的份额变化（百分点）；多国表现模式检查各报告国的区间增长率；双边模式检查所选各商品的区间增长率。数据、分母和缺失处理沿用原分析引擎，不能将不同国家的报告金额合并为全球总额。

每个对象保留各窗口的十进制计算值、金额变化、证据ID、分析ID和所属窗口。份额或增长率的正负方向在后端判断，前端不重算统计指标。

诊断分类如下：

- 方向反转：至少两个可计算窗口分别出现正、负方向；即使其他窗口缺失也可判断已观察到反转，但同时保留覆盖不足标记。
- 所选窗口均上升、均下降、均持平：至少两个窗口，且所选窗口全部可计算并满足相应方向。
- 方向相同但含持平：全部可计算，正值与零或负值与零共存。
- 证据不足：单窗口，或缺失使其他方向判断无法成立。

计数“窗口覆盖不足”指指标无法计算，不单指CSV记录不存在：增长率基期为零、市场分母不可用也属于不足。它可与方向反转计数交叉；各卡片不相加为总数。单窗口全部有记录时，覆盖不足可以为零，但不能称作跨窗口方向一致。

目标市场额外检查根分析窗口的金额变化与份额变化是否反向。即使根基期未勾选做敏感性比较，此项仍使用根分析基期，并保留相应证据。无论金额、份额是否同向，都不能据此认定竞争力变化或政策因果。

## 页面与导出闭环

“研究诊断”提供可点击计数卡片、分页热力矩阵、搜索与分类过滤、逐对象判断核查、证据抽屉，以及“加入研究笔记”。国家代码优先精确匹配，其他输入按名称搜索。图表与表格显示相同一页的数据；全量导出不受筛选、搜索或分页影响。

微小非零变化不会被诊断算法当作零。页面与报告使用科学计数法显示会被格式化成零的微小值，保留方向。灰色表示证据不足，点击证据查看原始输入。

修改基期但尚未更新时，旧结果明确标记为待更新；禁用诊断导出与加入笔记，防止把旧结果当成新窗口结果。生成的笔记可编辑并随原有保存、恢复、报告导出流程保留。诊断窗口选择本身没有写入用户保存记录，独立复算包保存完整诊断参数。

诊断报告为离线HTML，包括全部对象、所选窗口、方向分类、金额份额对照、公式、记录ID和来源。复算包另外包含diagnostic.json、backend/diagnostics.py和reproduce_diagnostic.py。运行脚本会同时核对根分析、所有诊断窗口、分类、证据及数据指纹。

示例报告在`研究成果/研究诊断示例`，由`scripts/build_diagnostic_case.py`生成；原主案例和宿主预实验冻结输入不改。

## 接口

`POST /api/diagnostics`，以及`POST /api/diagnostics/report`、`POST /api/diagnostics/bundle`，使用现有文档请求字段：spec、expected_analysis_id、source_saved_id、title、note；增加可选base_years（一至六个整数）。参数变化不重新解释已保存的原分析，数据指纹不一致时拒绝诊断和导出。详情以`/openapi.json`为准。

## 验证与实际限制

- 全量91项pytest检查通过，包含29项新增诊断检查：精确方向、单窗口、零分母、缺失、不变性、三种模式、扩展行业、错误参数、版本守卫、HTML转义、页内引用及真正解压后的独立复算。
- 美国乘用车韩国、德国、加拿大、日本的四窗口份额变化，使用Fraction从CSV独立计算核对。
- Edge实测主案例加载、搜索、证据抽屉、笔记添加与撤回、更新窗口后导出、HTML下载；390像素页面无整体横向溢出。
- 旧预实验冻结文件及首次回答机械检查仍通过；不新增模型成绩或真实用户试用成绩。
- ECharts改为注册所需折线、条形、热力图和相关组件，生产JS由上一版约1404KB降至约865KB，gzip约288KB；仍有大分块提示，未宣称完成网络性能基准。

这是一项描述性敏感性诊断，不是显著性检验、预测或因果识别。窗口重叠，长短区间增长率未年化，基期一致不表示其他时期也成立。真实模型接入、独立保留题集评价和真实用户操作试用仍待完成。
