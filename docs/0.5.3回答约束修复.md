# 0.5.3：四类回答约束修复

本轮只修复代码与页面，不追加真实模型调用；旧3题、33题和AI辅助评价均保持原始记录。计算引擎仍为0.1.0，数据及分析ID口径不变。

## 行为变化

| 问题 | 修复后的行为 |
| --- | --- |
| 解释当前报告国、伙伴角色和流向，却要求补充伙伴 | 识别明确的当前范围说明，直接读取已选参数与引用证据，标注“当前范围规则核查（未调用模型）”；不会把新年份、新国家或数值请求当作已知角色问题处理 |
| 双边模式重复传入partners或partner工具 | 仅当参数与当前固定伙伴一致时规范化为双边总览/窗口查询；记录原规划和有效规划。不同伙伴拒绝，保留目录、年份和重复参数校验 |
| 数值字段不符合证据 | 向模型提供逐证据字段白名单。operands.base等路径仅在真实base存在时解析；share0/share1仅在相应s0/s1存在时解析为原始份额比例，单位沿用比例。模型自填数值、未知字段和路径继续拒绝，修正记录保留 |
| 多国多窗口只回答部分数值 | 服务端从当前证据建立国家×窗口×指标清单，提示模型逐项回答，允许最多24条论断。漏项标为incomplete，页面列出程序生成的全部要求数值和“模型漏项”；不伪造模型新增论断，不自动重试 |

## 边界

这是当前问题的工程修复与离线回归，不证明修复后真实模型成功率或语义准确率。角色说明规则只覆盖可明确识别的当前范围问题，自由提问仍依赖模型。证据表完整不代表模型正文正确；份额、因果和来源口径仍需语义复核。

修复阶段只做离线核验。后续按用户要求新增针对性真实复测：13份已知问题，其中6份规则答复、7份模型答复，实际11次API请求；13/13份机械检查通过，17/17项要求数值匹配。首次结果与剩余措辞问题见`研究成果/真实模型试运行/0.5.3针对性复测报告.md`。

“试用与演示”分别展示旧版本评测与新定向复测，不将规则答复混算成模型成功。独立人工语义评价仍待完成。
