# 0.5.4 回答措辞与展示修复

本次处理已知的百分比／百分点混用、简单数值问题回答冗长。参赛材料与视频暂不更新。

## 行为

- 提示模型合并同一对象、同一窗口的相关指标，简单数值问题通常一至三条；多国多窗口仍优先保证完整覆盖。不要求的分解和建议不主动追加。
- 明确增长率使用百分比，份额差值使用百分点。反驳错误数值时使用“题述增长率与证据不符”，避免重复或改写错误数值。
- 服务端检测“增长……个百分点”等高置信度疑似混用表达，返回所在论断或边界说明的索引及警告。页面显示核查提示，相关原文折叠保留，证据数值和单位仍可核查。
- 简单数值问题按既有证据覆盖规则选出直接回答要求指标的论断，其余内容放在“展开补充分析”。因果、政策、分解等解释性提问不自动折叠；多窗口不得因此丢失所问指标。
- 原始模型论断、调用记录、数值绑定及覆盖状态不被改写。`presentation`仅为展示元数据；`answered`仍仅表示机械约束通过，不能等同语义正确。历史冻结评测保留原样。

## 验证

- 全部后端测试：132项通过，保留既有Starlette/httpx弃用提示。
- 新增7项离线回归，含真实14条冗长回答回放、疑似单位混用及合法百分点表达。
- 加拿大可可旧回答：14条原始论断，默认3条，补充11条；所问3项数值仍全部覆盖。
- 德中茶叶旧回答：“所谓增长九百九十九个百分点”触发边界说明警告，原文保留可展开。
- 真实浏览器：六次AI请求全部拦截为离线回放；覆盖漏项提示、比例单位、规则答复说明、补充展开、原文展开、390像素手机布局通过，无未捕获页面异常。
- 前端生产构建成功，仍存在既有大包体积提示。

本轮无真实模型调用、无新费用；生成提示调整尚未做在线复测。单位检测是保守的局部规则，不能替代完整语义审查，也不能保证识别所有措辞错误。作者试用反馈和独立人工评价仍分别保留。
