# 架构与接续开发

## 授权范围与项目定位

本项目为校园AI大赛赛道四作品，与同级“贸研核查”独立，不修改旧项目。按用户已确认方案，支持多国、多商品，不固定中国或茶叶。当前用户明确暂不提供模型，先开发基础应用和接入接口。不得伪造模型回答或试用反馈。

## 入口与接口

0.2.0补充：`GET /api/cases`提供三类真实研究案例；`POST /api/document/report`和`/bundle`接受标题、笔记、预期分析ID及可选来源记录ID。恢复记录返回`saved_record`元信息。计算结果不包含笔记，导出包通过`annotation.json`独立保留；新增开发请保持这一分离，避免破坏数值复现。保存记录ID已改为独立UUID，不能再假设记录ID等于分析ID。

`run.py`把项目`.vendor`加入模块搜索路径，启动FastAPI并统一提供`frontend/dist`。仅监听127.0.0.1，避免前后端分开启动。前端开发由Vite代理`/api`到8765。

核心接口：

| 接口 | 功能 |
|---|---|
| GET /api/datasets、/api/datasets/{id} | 数据包和覆盖、来源 |
| POST /api/analyse | 确定性分析及内嵌证据 |
| POST /api/saved、GET /api/saved/{id} | 保存和恢复完整结果快照 |
| POST /api/export/report、/bundle | 带SVG图表HTML、可复算ZIP |
| GET /api/import/template、POST /api/import | 标准CSV模板与导入 |
| GET/POST /api/model | 本地模型配置；密钥只写 |
| POST /api/ai/ask | 受限工具选择、结果解释和引用校验 |

详细模式参数以`backend/analysis.py`的Spec和`/openapi.json`为准，禁止前端自行另算统计结果。

## 计算口径

- 目标市场模式固定为目标国报告的进口，世界进口金额为分母。
- 双边模式使用报告国、伙伴、流向，显示所选商品金额及其变化。
- 多国模式分别使用各国世界总额，不把样本合计称作全球总额。
- 所选商品每项都需有记录，缺一不按零补齐。
- 同一比较范围必须使用同一分类版本，父子商品不能同时求和。
- 计算用Decimal，展示用浮点。分解恒等式误差只来自展示精度。
- 非明确零记录不判断进入或退出。未分配伙伴保留来源记录，不创造跨年身份。
- 未能确认完整市场构成时，HHI为空；仅输出列示头部份额和残差。

## 数据处理中的真实问题

WITS页面四个伙伴的链接错误指向WLD：科特迪瓦、圣巴泰勒米、荷属圣马丁、博奈尔。收集器按名称修正，依据保留的联合国partnerAreas参考表，原始页面不改。

部分页面出现多条名称与代码均为Unspecified/UNS的记录。不能假定它们是同一个国家，也不能不经解释去重。当前赋予来源行级身份，标记unallocated，排除跨年国家比较并保留在原始与标准记录中；差额体现在覆盖和变化对账残差。

## AI边界

两轮真实模型请求：第一轮从固定工具名选择，只读当前分析；第二轮基于证据包生成中文解释。禁止执行模型生成代码。回答限制自由数字，引用必须存在。该限制不能证明解释语义正确，正式评测仍需人工判定。

配置仅支持Ollama和兼容聊天接口，不假定某个付费服务余额。用户未连接模型时正常返回“尚未连接”，基础分析独立使用。

## 接续顺序

1. 用户具备模型后，验证适配器、超时、JSON格式及一次真实工具解释。
2. 检查模型引用与语义，允许改进输出协议，但保留明确的数值校验。
3. 按evaluation规范冻结正式评测及参考判据。调试过的题不得继续称作未见测试。
4. 由用户选择并理解主案例，以同口径数据形成分析报告。
5. 完成真实学生操作试用，记录失败与改进。
6. 冻结功能，完成申报材料和现场演示。

不要为了扩大范围优先增加预测、多智能体讨论或复杂网络图；当前更需要真实模型验证、分析价值与用户可用性证据。
