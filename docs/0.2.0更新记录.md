# 0.2.0 更新记录

日期：2026年10月18日（Asia/Shanghai）。用户已启动初版并反馈可用，本轮继续完善试用流程；该反馈属于非结构化体验，不计算任务成功率或节省时间。

## 新增与修复

1. 首页加入三个真实数据研究案例：美国乘用车供应变化、中德日乘用车出口比较、加拿大含可可食品。案例预置问题和条件，数值仍实时计算；不预写获奖结论。
2. 当前分析可编辑报告标题和最多5000字研究笔记。浏览器按分析ID保留草稿；正式保存后笔记进入本地记录、HTML报告和复算包的annotation.json。
3. 同一分析条件可保存多份独立记录，记录ID与确定性分析ID分开，不再覆盖原记录。原四字段SQLite表自动添加笔记列，旧记录仍可读取。
4. 恢复快照后，报告直接使用该快照，不重新计算并替换原结果。新保存/导出可检查预期分析ID；当前数据版本变化时提示重新分析。复算ZIP仍要求源文件指纹与旧结果一致。
5. 笔记与计算分开保存，复算只比较确定性分析结果。HTML中的笔记转义并保留换行，明确标注为使用者记录。
6. 案例切换和加载期间禁用笔记编辑，防止内容写入尚未完成的新分析。保存及恢复期间禁用重复操作。AI异步结果仅回到对应分析ID，数据版本变化时不给旧图表附上新回答。
7. 模态框内直接显示错误信息。页面加入内嵌空图标，避免浏览器请求不存在的favicon。

应用版本为0.2.0；计算口径和计算引擎仍为0.1.0，没有通过改公式制造新发现。
