# 0.3.0 证据工具与接续说明

本版完成主案例预实验发现的指定伙伴、时间窗口、引用命名空间和数值绑定四项接口缺口。分析引擎仍为0.1.0，原分析ID和冻结输入不变。模型服务尚未配置，没有付费调用。

## 页面体验

载入美国乘用车案例，进入“AI分析台”的“伙伴与时间窗口核查”。指定CAN、JPN、GIB，勾选2019—2023和2022—2023，点击“核查所选窗口”。无需模型。

加拿大份额变化分别约−4.48和+0.92个百分点；日本金额增加并不意味着长窗口份额上升；直布罗陀报告期缺失，显示为空，不按退出处理。点击各行证据编号，抽屉显示该窗口、完整分析ID、公式、输入与来源。手机宽表可横向滚动。

## 接口

`POST /api/tools/execute` 接收 `spec`、`expected_analysis_id`、`plan`。

```json
{
  "tool": "window_compare",
  "partners": ["CAN", "JPN", "GIB"],
  "base_years": [2019, 2022]
}
```

上述JSON为plan示例。tool允许overview、contributions、structure、comparison、partner、window_compare；clarify只供模型规划阶段使用。partner必须指定伙伴。最多六个伙伴、四个基期，禁止重复参数，窗口比较保持报告期、报告国、商品、数据包、流向不变。代码须存在于当前范围的数据目录，年份须在目录且早于报告期。指定供应伙伴适用于目标市场模式。未列示对象单列unavailable_partners，不能据此认定进入或退出。

返回windows、evidence、tool_calls、data_sha256；证据ID为`analysis_id:E编号`。证据保留原记录，模型接收的紧凑上下文去除records和record_ids，界面和日志保留它们。

`POST /api/ai/ask`增加expected_analysis_id。第一轮模型选择受限工具和参数，第二轮产生claims。每条包含text、citations及可选numbers：

```json
{"citation":"完整分析ID:E编号","field":"share_change_pp"}
```

数字项仅允许citation和field；field须为被引证据的operands字段或result。后端填入value、unit、label，保留原始十进制字符串和空值；前端只格式化显示。模型自行填写value、裸E编号、错误窗口、未知字段、正文或limitations中的阿拉伯数字都会被拒绝。数字存在与引用有效不保证自然语言语义正确，仍需人工复核，也不能证明因果关系。

回答日志按根分析ID存储，包含各窗口、完整证据、工具参数及数据指纹，现有复算包会带出这些日志。计算复算与模型文字分别理解；本次没有向用户数据库写入协议测试回答。
